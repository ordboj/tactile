# Copy rules

This file is team text.
It sets the rules for player text.
Ticket: TAC-8.
Source: [docs/product/mission-1-spec.md](../product/mission-1-spec.md) sections 5, 6, 8, and 8a.

The player lines for Part A are in [docs/learning/part-a-tutorial-text.md](part-a-tutorial-text.md).
This file lists banned words.
Those words are here so the team can ban them.
Do not show this list to the player.

## Text form

The game uses text only.
All feedback is written text.
The game has no guide voice.
No audio file speaks a player line.
Do not play a voice for the name Walker.

## Person

A player line uses the third person.
The subject is the walker.
Use this pattern: "The walker waits."

Do not use "you" in a player line.
Do not use "your" in a player line.
Do not give a command to the player in a feedback line.

One line is the exception.
The spec locks that line.
Do not rewrite it.
The line is in the next section.

## Length and words

Each player line has a target of 12 words or fewer.
Every Mission 1 line in the tutorial file is at or under that target.
Put each player line on its own row on a phone.
Use plain words.
Use one idea in each line.
Use a simple tense.

## Tone

Use a kind tone.
Use a calm tone.
Do not blame the player.
Do not use these blame words in player text:

- wrong
- fail
- failed
- bad
- mistake
- fault

Safe play scores higher than speed.
Do not praise speed.
Do not tell the player to hurry.

## Safety claims

Do not write that a stopped car makes a cross safe.
Do not imply that a stopped car makes a cross safe.
Do not add a new traffic-safety claim in player text.
A tip is a traffic-safety claim.
Tips are out of scope for this file.
The tip list is TAC-9.
Each tip needs a real source.
Each tip needs the reviewer.

## Banned words

Player text must not use these words and phrases:

- blind
- blindness
- visually impaired
- simulate
- simulation
- experience what it is like
- disability
- awareness
- cane
- braille

The ban covers player text.
The ban covers store text.
The ban covers marketing text.
Match a banned word inside a longer word.
Match a banned phrase as a phrase.

This file is not player text.
This file lists the banned words so the team can check.

## Required line

The game shows this exact line:

```text
This is a game. Follow local traffic rules.
```

Show the line in two rows on a phone:

```text
This is a game.
Follow local traffic rules.
```

The first row has 4 words.
The second row has 4 words.
Do not add words.
Do not remove words.
Do not change the order.

Show the line in two places:

- At the start of Mission 1, before the first tutorial step.
- At the top of Settings.

Leave the line on screen until the player leaves that screen.
The line is text.
The line is not a voice.
The line is not a tip.

## Failure text

Part A has no failure flow.
Do not show failure text in Part A.

The failure flow starts in Part B.
The failure flow has five steps.
The steps are freeze, replay, missed cue, rewind, and one tip.
No frame shows contact.
No frame shows impact.
No frame shows injury.

The replay text names the missed cue.
Use the pattern in the tutorial file.
The pattern is: "The walker crossed while the car sound came closer."

The spec example omits the word "The".
The language rule in the spec uses "The walker".
These copy rules use "The walker".

## Checklist

A reviewer can use this list for a new player line.
Each answer must be yes.

- The line uses the third person.
- The line does not say "you".
- The line does not say "your".
- The line is not a command to the player. The required game line is the only exception.
- The line has 12 words or fewer.
- The line has one idea.
- The line uses plain words.
- The line does not use a word from the banned list.
- The line does not use a phrase from the banned list.
- The line does not blame the player.
- The line does not praise speed.
- The line does not say that a stopped car makes a cross safe.
- The line does not imply that a stopped car makes a cross safe.
- The line is text. It is not a voice.
- A Part A line does not start the failure flow.
- A replay line names the missed cue.
- The required game line matches the spec words.
- The required game line shows at the start of Mission 1.
- The required game line shows at the top of Settings.
